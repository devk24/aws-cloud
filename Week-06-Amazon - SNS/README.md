# Week 6 - Amazon Simple Notification Service (SNS)

## Overview

Amazon Simple Notification Service (Amazon SNS) is a fully managed messaging service that enables applications to send notifications and messages to multiple subscribers. It supports both application-to-application (A2A) and application-to-person (A2P) communication.

SNS uses a publish/subscribe (Pub/Sub) messaging model, where messages published to a topic are delivered to all subscribed endpoints.

---

## Key Features

- Fully managed messaging service
- Publish/Subscribe (Pub/Sub) architecture
- Supports multiple subscribers
- High availability and scalability
- Secure message delivery
- Integration with various AWS services

## Key Takeaways

- Amazon SNS is a fully managed messaging service.
- It uses a Publish/Subscribe (Pub/Sub) model for message delivery.
- A single message can be delivered to multiple subscribers.
- SNS integrates with services such as AWS Lambda, Amazon SQS, and CloudWatch.
- It is commonly used for notifications, alerts, and event-driven applications.
